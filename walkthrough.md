## 3. Walkthrough Workflow Summary

1. **Dashboard Overview**: Displays real-time executive KPIs (Total Projects, Sources Collected, Extracted Findings, Running Workflows, Completed Workflows, Contradiction Count).
2. **Autonomous Research Commissioning**: User inputs a high-level question or selects a sample prompt (e.g. *"How is AI transforming manufacturing operations?"*).
3. **Live 11-Stage Pipeline Tracker**: Real-time progress bar and state machine stepper tracking sub-question planning, public web retrieval (DDGS, Wikipedia, ArXiv), rule-based reliability evaluation (0–100 score), verbatim quote extraction, finding categorization, contradiction detection, and conclusion generation.
4. **Verifiable Traceability Lineage**: Clicking **"Why this conclusion?"** opens a modal displaying the exact supporting findings, verbatim quotes, original URLs, and non-LLM reliability breakdowns.
5. **Knowledge Base Search**: Cross-project hybrid search across all historically ingested sources, findings, and conclusions.
